# CyberTrail 离线地图制作指南

在户外越野、登山探险等完全没有移动网络信号的极端环境中，**离线瓦片地图**是确保您不迷失方向的关键。CyberTrail 提供了卓越的离线地图包（MBTiles 格式）加载支持。本指南将指导您如何为 CyberTrail 准备并制作高质量的离线瓦片地图。

---

## 1. 离线地图格式与存放路径

### 推荐格式
* **栅格瓦片地图包**：`world.mbtiles`（标准 SQLite 数据库打包格式）。
* 当前版本主要支持 **Raster MBTiles（栅格瓦片）**，能完美渲染各种卫星影像、地形晕渲图、等高线混合图以及纸质扫描地图。

### 存放路径
请将制作好的 `.mbtiles` 格式地图包放入您的手机存储中：
```bash
/storage/emulated/0/CyberTrail/Maps/
```
> **提示**：如果在该目录下存入多个 `.mbtiles` 文件，CyberTrail 会自动识别并在离线地图切换列表中列出，供您在不同比例尺、不同地表纹理（如卫星图与等高线图）之间自由切换。

## 2. 离线地图制作流程

### 方法 A：使用 QGIS 自助导出（推荐，零代码）
QGIS 是一款强大的开源地理信息系统软件，非常适合用于离线地图的精细化剪裁和制作。

1. **准备底图**：
   * 打开 QGIS，在左侧浏览器面板中双击 `XYZ Tiles`，添加标准在线地图源（例如高德卫星图、天地图、谷歌卫星图或 OpenStreetMap）。
   * 如果需要等高线，可在 QGIS 中导入高程 DEM 提取等高线并作为图层覆盖在卫星图上方。
2. **定位与构图**：
   * 缩放至您要进行越野探险的目标山区/路线。
3. **导出 MBTiles**：
   * 在顶部菜单栏中选择 `Processing` -> `Toolbox`（工具箱）。
   * 搜索并打开 `Generate XYZ tiles (MBTiles)`（生成 XYZ 瓦片）。
   * **Extent（范围）**：选择 `Use Map Canvas Extent`（使用当前视口范围）或手动在地图上框选目标山区。
   * **Minimum Zoom（最小缩放）**：推荐设置见后文。
   * **Maximum Zoom（最大缩放）**：推荐设置见后文。
   * **DPI（分辨率）**：默认 96 即可，高分屏可选择 192。
   * **Output file**：保存为 `.mbtiles` 文件，并将其传输至手机的 `CyberTrail/Maps/` 文件夹中。

### 方法 B：使用 Google Colab 脚本自动下载
对于无 QGIS 基础或希望批量下载大面积瓦片的用户，推荐使用基于 Python 的 Colab 自动化脚本：

1. **配置范围**：
   * 在 Colab 中定义您目标山区的经纬度 Bounding Box（例如 `[min_lat, min_lon, max_lat, max_lon]`）。
2. **下载并拼接**：
   * 脚本会自动请求无水印高清瓦片源，并在多线程下并行下载所有 PNG/JPG 图像。
3. **打包为 MBTiles**：
   * 自动调用 `sqlite3` 库，建立瓦片金字塔表格：
     ```sql
     CREATE TABLE tiles (zoom_level integer, tile_column integer, tile_row integer, tile_data blob);
     ```
   * 脚本打包压缩完成后直接输出一个 `map.mbtiles`。您只需一键下载并拷贝进手机中即可。

### 方法 C：GitHub Actions 云端自动构建
我们为开源社区和进阶领队提供了自动化云端地图构建方案：

1. **提交配置文件**：
   * 在您的 GitHub 派生（Fork）仓库中修改 `.github/workflows/map-builder.yml`，填入目标线路（如“四姑娘山大峰越野线”）的轨迹经纬度边界。
2. **云端无感构建**：
   * 触发 Actions 工作流，GitHub 云端服务器将自动调用 Tilezen/Mapnik 工具链进行无感拉取、高画质渲染与 MBTiles 封装。
3. **下载即用**：
   * 构建完成后，您可以直接在 Run Artifacts 或 Release 页面下载打包好的极精细离线地图。

## 3. 推荐缩放等级（Zoom Levels）

瓦片地图是由不同比例尺的方块金字塔组成的。缩放等级越高，地图越精细，但文件体积呈指数级增加。推荐根据应用场景合理设置：

| 场景 | 推荐缩放等级 | 像素精度 | 说明与建议 |
| :--- | :--- | :--- | :--- |
| **全国/大区全览** | `1 ~ 10` | 数公里级 | 用于大尺度概览、跨省自驾路线示意。文件极小（约几MB），推荐作为底图长期保留。 |
| **城市/县域级** | `11 ~ 15` | 百米至十米级 | 覆盖城市街区、主干道及乡村路网。体积中等（50MB ~ 200MB）。 |
| **山区/探险级** | `12 ~ 17` | 5米级 | **越野跑、重装穿越、登山探险黄金区间**。能清晰分辨林道、防火道、急弯和山脊。通常只剪裁目标山域，体积约 100MB ~ 1GB。 |

## 4. 未来预留与规划（开发中）

为不断提升野外探险的流畅度与显示效果，CyberTrail 团队正在积极研发以下高级特性：

* **矢量瓦片支持 (Vector Tiles) [开发中]**：
  * **简介**：未来版本将无缝支持 `.mbtiles` 格式的矢量数据源。
  * **优势**：地图体积将缩小 80%，且支持无级缩放、地图内文字智能旋转（不倒置）、任意切换主题样式。
* **等高线动态叠加引擎 [开发中]**：
  * **简介**：支持直接在矢量瓦片层上根据本地高程数据动态渲染等高线，无需预渲染大量的栅格图片。
