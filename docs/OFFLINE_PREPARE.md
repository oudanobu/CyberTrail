# CyberTrail 离线准备与全功能离线工作指南

CyberTrail 是一款专为极致越野探险、高山搜救与户外徒步设计的**完全离线自治**地理系统。无论在没有基站信号的海拔五千米山脊，还是在密林深处的峡谷，只要做好合理的离线数据准备，CyberTrail 就能提供不打折扣的地图呈现、高程分析、坡度防护、轨迹记录与自诊断排查。

本指南将向您展示如何在出发前完美准备您的离线移动地理数据库。

---

## 1. 统一数据目录树架构

CyberTrail 在手机的共享内部存储（或大容量 SD 卡）中设立了一个统一的物理数据根目录 `CyberTrail`。

### 核心目录结构
请确保您的手机闪存中存在以下对应的子目录结构：

```text
/storage/emulated/0/CyberTrail/
├── Maps/             # 离线瓦片地图存储目录（推荐存放 world.mbtiles）
├── dem/              # 离线真实高程数据目录（支持存放 .hgt, .tif, .tiff 格式瓦片）
├── Tracks/           # 运动轨迹存储目录（记录并保存您个人的历史运动轨迹）
├── Routes/           # 户外规划路线导入目录（支持直接导入标准 .gpx/.kml 格式）
├── POI/              # 离线兴趣点与标记航点数据（支持存放自定义 .kml 地标）
├── Photos/           # 户外探险沿途关联的地理照片存储（保存您在特定轨迹点的拍摄成果）
├── Export/           # 数据导出成果目录（系统导出 GPX 轨迹、诊断报告和 KML 的物理位置）
└── diagnostic/       # 离线诊断快照目录（存储传感器校验、地图缺失、高程空洞日志）
```

### 目录用途详解
* **`Maps/`**：存放高画质离线底图。系统可以并发并独立加载数个不同的离线地图，支持单图层自由切换。
* **`dem/`**：存放高精地形数据。没有它，海拔、坡度、坡向数值都将因缺少真实数据参考而强制显示为 `N/A`。
* **`Tracks/`** & **`Routes/`**：存储户外安全生命线。您可以将领队给您的 `.gpx` 文件直接拖拽至 `Routes/` 中，APP 会自动加载并在离线地图上渲染出引导线。
* **`POI/`**：存放关键露营点、水源地、撤退点以及救援坐标。
* **`Photos/`**：配合相机，可将带有经纬度元数据的照片直接锚定在您的轨迹时间轴上。

## 2. 首次启动与离线自诊断步骤

在您收拾行囊、向没有信号的原始森林出发之前，**请务必在有网络的城市环境或家中使用 APP 的“自诊断页面”进行一次离线完备度核查**：

1. **打开自诊断**：
   * 在主界面底部或设置菜单中，找到并点击 **🏔️ 离线自诊断 (Offline Diagnostics)**。
2. **核对核心路径与文件数量**：
   * 自诊断系统会自动扫描 `/CyberTrail/` 下的各个物理节点。
   * 查看 **真实 DEM 离线高程系统状态**：
     * **状态**：显示“已加载 DEM”代表高程卡读取正常；如果显示“未发现 DEM”，请确保您的 HGT 格式文件已被放进 `dem` 文件夹中。
     * **文件数量**：显示已载入的文件个数。
     * **覆盖区域**：系统会自动提取文件名中的地理参数，智能算出该高程数据代表的全球经纬度网格范围（例如 `N39°~N41°, E123°~E126°`）。请确认该覆盖区域与您的探险目的地完全契合。
     * **当前高程来源**：将明确提示当前正在解析的是 `真实 DEM (SRTM)` 或 `真实 DEM (Copernicus DEM)`。
3. **自诊断快照输出**：
   * 完成检测后，页面会自动在界面生成诊断详情列表，您也可以一键导出诊断文件到 `Export/` 目录下，用于提前排除任何离线盲区。

## 3. 完全离线环境下的工作流程

当您进入无信号荒野（开启飞行模式）后，CyberTrail 将在全密封离线系统下按以下逻辑工作：

```text
 🛰️ 卫星 GPS 定位
      │
      ▼
 📍 捕捉到经纬度 (Lat, Lon)
      │
      ├─► [离线地图引擎] ──► 匹配并渲染 Maps/ 文件夹下的本地 MBTiles
      │
      └─► [离线 DEM 系统] ──► 查询 dem/ 文件夹下的真实高程切片
            │
            ├─► 进行双线性平滑插值，计算出您的 真实海拔 (Alt)
            ├─► 计算周围 2x2 格网梯度，解算出精确 坡度 (Slope) 和 坡向 (Aspect)
            │
            ▼ (若未检测到对应的 DEM 切片)
          提示“DEM未加载”，所有衍生高程、坡度指标显示为 N/A，杜绝伪造假数据
```

## 4. 未来预留与规划（开发中）

为了构建功能更加完备的野外离线保障体系，CyberTrail 在系统底层为以下高级离线特性预留了核心计算接口：

* **完全本地离线路径规划 (Route Planning) [开发中]**：
  * **简介**：基于本地高维矢量路网拓扑，实现无网下的单兵自动多点最优路径导航与避障重规划。
* **惯性导航与推算 (Inertial Navigation) [开发中]**：
  * **简介**：在遇到大峡谷、厚重原始林冠层等 GPS 信号严重受阻丢星的情况下，利用手机三轴陀螺仪、加速度计和气压高度计，通过捷联惯导（SINS）算法对您的位置和高度进行积分推演。
* **基于传感器特征分析的智能计步器 (Step Counter) [开发中]**：
  * **简介**：无需穿戴设备支持，直接解算移动端物理传感器的重力加速度波峰与周期特性，在极低能耗下离线记录您的一日探索步数。
